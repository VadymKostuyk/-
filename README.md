## 🚀 Як використовувати

### 1. Завантаження на GitHub Pages

1. Створіть новий репозиторій на GitHub
2. Завантажте всі файли в репозиторій
3. Перейдіть в **Settings** → **Pages**
4. Виберіть гілку `main` та папку `/ (root)`
5. Натисніть **Save**
6. Ваш сайт буде доступний за адресою: `https://ваш-нікнейм.github.io/назва-репозиторію/`

### 2. Редагування контенту

#### Зміна тексту
Відкрийте `index.html` і знайдіть потрібний текст між тегами.

#### Зміна номерів
Знайдіть секцію `<!-- Rooms Section -->` та редагуйте:
- Назву номера: `<h3 class="room-name">Назва</h3>`
- Опис: `<p class="room-desc">Опис</p>`
- Ціну: `<span class="room-price">ціна</span>`
- Зображення: `src="images/назва.jpg"`

#### Зміна телефонів
Знайдіть всі `tel:+380677659478` та замініть на свій номер.

#### Зміна зображень
1. Додайте нове зображення в папку `images/`
2. Змініть шлях в HTML: `src="images/нове-зображення.jpg"`

### 3. Редагування стилів

Відкрийте `css/style.css`:

- **Колір основний**: змініть `--primary: #2d5a3d;`
- **Шрифт**: змініть у `<head>` посилання на Google Fonts
- **Розміри**: змініть змінні `--radius`, `--radius-lg`
